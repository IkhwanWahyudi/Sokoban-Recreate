# Sokoban Recreate

A recreation of the classic puzzle game Sokoban, built as a simple desktop game using Processing. The player pushes crates onto marked target tiles to complete each stage, with multiple stages of increasing difficulty.

## Features

- Classic Sokoban puzzle mechanics (push crates onto targets)
- Multiple stages with increasing difficulty
- Menu, loading screen, and credits screen
- Custom audio and sprite assets

## Tech stack

- **Engine/Language:** Processing (`.pde`)

## Repository structure

```
├── Audio/             # Sound effects and music
├── Images/            # Sprites and visual assets
├── Main.pde           # Entry point
├── Menu.pde           # Main menu screen
├── loading.pde        # Loading screen
├── Stage1.pde          # Stage 1
├── Stage2.pde          # Stage 2
├── Stage3.pde          # Stage 3
├── FinalStage.pde      # Final stage
└── credits.pde         # Credits screen
```

## Getting started

This project runs in the [Processing IDE](https://processing.org/download).

1. Install Processing
2. Open `Main.pde` in the Processing IDE
3. Click Run
